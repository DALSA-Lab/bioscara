\doxysubsection{Detailed Description}
Generic base class to control a single joint.

State flags transmitted with every I2C transaction. 

The transmission flags purpose are to transmit the joints current state. Note\+: They can not be used as error indication of the execution of a transmitted write command, since commands are executed after the I2C transaction is completed.
